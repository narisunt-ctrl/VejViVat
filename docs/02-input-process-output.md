## 2. รายละเอียดข้อมูลนำเข้า (Input Specifications)

### 2.1 ข้อมูลประชากรและสรีรวิทยา (Patient Demographics & Vitals)
- **HN (Hospital Number):** เช่น `HN-2568001` ถึง `HN-2568030` หรือเลข HN ที่สร้างใหม่
- **ช่วงอายุ (Age Groups):** จำแนกเข้าสู่ 3 ช่วงวัย (อายุสมุฏฐาน):
  - *ปฐมวัย (0-16 ปี):* อาโปธาตุ (เสมหะสมุฏฐาน)
  - *มัชฌิมวัย (16-32 ปี):* เตโชธาตุ (ปิตตะสมุฏฐาน / โลหิตเด่น)
  - *ปัจฉิมวัย (32 ปีขึ้นไป):* วาโยธาตุ (วาตะสมุฏฐาน)
- **สัญญาณชีพ (Vitals):**
  - อุณหภูมิกาย (`btemp`): ไข้ต่ำ (>= 37.3°C), ไข้สูง (>= 38.0°C กระตุ้นเตโชธาตุ และเตือน Red Flag ห้ามนวด)
  - ความดันโลหิต (`sbp` / `dbp`): >= 140/90 mmHg (ระวัง), >= 180/110 mmHg (วิกฤต ห้ามนวดเด็ดขาด ต้องส่งต่อทันที)
  - ชีพจร (`pr`): >= 95 bpm กระตุ้นหทัยวาตะ, <= 55 bpm เฝ้าระวัง
  - อัตราการหายใจ (`rr`), น้ำหนัก (`weight_kg`), ส่วนสูง (`height_cm`), ดัชนีมวลกาย (`bmi`)

### 2.2 สัญญาณเสียงบอกอาการคนไข้ (Voice Audio Stream Input)
- บันทึกสัญญาณเสียงผ่านไมโครโฟนเบราว์เซอร์ (Web Audio API / Web Speech API)
- รองรับภาษาไทย ถอดรหัสคำศัพท์อาการ (เช่น "ปวดบั้นเอวร้าวลงขา", "ชาปลายมือปลายเท้า", "แน่นหน้าอก", "แสบท้อง")
- สกัดคำสำคัญเข้าสู่ระบบ Symptoms อัตโนมัติ เพื่อนำไปคำนวณสมุฏฐานธาตุและวินิจฉัยคู่ขนานสดทันที

### 2.3 สภาวะแวดล้อมและช่วงเวลา (Ambient & Temporal Context)
- **พิกัดและสถานที่:** ละติจูด, ลองจิจูด, ชื่อสถานพยาบาล (ครอบคลุมทั้ง 4 ภูมิภาค)
- **อุณหภูมิภายนอก (°C) และความชื้นสัมพัทธ์ (%):** ดึงผ่าน Open-Meteo REST API
  - อุณหภูมิ >= 35.0°C: กระตุ้นเตโชธาตุ (+18) ลดอาโปธาตุ (-10)
  - อุณหภูมิ <= 22.0°C: กระตุ้นอาโปธาตุ (+15) วาโยธาตุ (+5) ลดเตโชธาตุ (-10)
  - ความความชื้น >= 80%: กระตุ้นอาโปธาตุ (+14)
- **กาลสมุฏฐาน (Kala Period):** จำแนกตามเวลาที่ตรวจ:
  - 06:00 - 10:00 น. / 18:00 - 22:00 น. = เสมหะกาล (อาโปธาตุ +10)
  - 10:00 - 14:00 น. = ปิตตะกาล (เตโชธาตุ +12)
  - 14:00 - 18:00 น. / 22:00 - 06:00 น. = วาตะกาล (วาโยธาตุ +12)

### 2.4 ประวัติยาแผนปัจจุบันและคลังยาหลักแห่งชาติ (Conventional Drug Formularies)
- **Active Conventional Medications:** ยาแผนปัจจุบันที่ผู้ป่วยใช้อยู่จริง (Generic Name, Strength, Dose, Frequency, Timing, Route)
- **NLEM Master Dataset:** ฐานข้อมูลยาแผนปัจจุบัน 1,080 รายการ ครอบคลุม 17 กลุ่มโรคสากล จากประกาศกระทรวงสาธารณสุข

## 3. รายละเอียดการประมวลผล (Processing Specifications)

### 3.1 การคำนวณสมุฏฐานธาตุ (Smutthan Calculation Engine)
- คะแนนเริ่มต้น (Baseline): แต่ละธาตุเริ่มที่ 25.0 คะแนน (ผลรวม 100 คะแนน)
- คำนวณผลกระทบสะสมจาก: 1) อุตุสมุฏฐาน 2) กาลสมุฏฐาน 3) อายุสมุฏฐาน 4) สัญญาณชีพ 5) อาการสำคัญ
- จำแนกสถานะ:
  - คะแนนสูงสุด >= 65: **กำเริบ (Aggravated)**
  - คะแนนสูงสุด <= 35: **หย่อน (Deficient)**
  - 36 - 64: **สมดุล (Normal)**

### 3.2 ระบบวินิจฉัยคู่ขนาน (Dual Diagnosis Matching Algorithm)
- จับคู่กลุ่มอาการเพื่อวิเคราะห์รหัสโรคแผนปัจจุบันสากล (Conventional ICD-10) ควบคู่กับรหัสการแพทย์แผนไทย (ICD-10-TM กลุ่ม U)
- คำนวณคะแนนความสอดคล้อง (Match Score: 0-100%) และระดับความเชื่อมั่น (HIGH / MODERATE / LOW)
- แสดงเหตุผลสนับสนุนสองศาสตร์ (Conventional vs Traditional Rationale)
- รองรับ Clinician Override บันทึกรหัสโรคและเหตุผลทางคลินิกโดยผู้ประกอบวิชาชีพ

### 3.3 การคัดกรองความปลอดภัยและข้อห้ามทำหัตถการ (Red Flag & Procedure Safety Service)
- **เกณฑ์คัดกรองฉุกเฉินเด็ดขาด (Critical Red Flags):**
  - สัญญาณโรคหลอดเลือดสมองเฉียบพลัน (FAST / Stroke Clues: ปากเบี้ยว แขนขาอ่อนแรง พูดไม่ชัด)
  - สัญญาณกลุ่มอาการหลอดเลือดหัวใจเฉียบพลัน (ACS: แน่นหน้าอกร้าวไปกราม/แขนซ้าย เหงื่อแตก)
  - อาการปวดท้องเฉียบพลันที่มีหน้าท้องเกร็งแข็ง (Acute Abdomen / Peritoneal Signs)
  - ภาวะลิ่มเลือดอุดตันในหลอดเลือดดำส่วนลึก (DVT: ขาบวมแดงร้อนข้างเดียว กดเจ็บ)
  - สัญญาณชีพวิกฤต: SBP >= 180 mmHg, DBP >= 110 mmHg, ไข้สูง >= 38.5°C
- **ข้อห้ามทำหัตถการนวดไทย:**
  - ห้ามนวดเด็ดขาดหากมีความดันวิกฤต หรือมีไข้สูง
  - ห้ามนวดดัดดึงรุนแรงในผู้ป่วยที่ได้รับยา Warfarin หรือ Aspirin/Clopidogrel เนื่องจากเสี่ยงต่อการเกิดจ้ำเลือดและเลือดออกในกล้ามเนื้อ/ข้อต่อ

### 3.4 การตรวจจับอันตรกิริยา (Two-Way HDI Matcher)
- อัลกอริทึมตรวจสอบคู่ยาเสี่ยงครอบคลุมทั้ง 30 เคส C01–C30:
  - **ความเสี่ยงสูง (HIGH):** เช่น Warfarin + ขมิ้นชัน/ขิง (เสี่ยงตกเลือด), Digoxin + ชะเอมเทศ (หัวใจเต้นผิดจังหวะ), Amlodipine + ชะเอมเทศ (วิกฤตความดัน)
  - **ความเสี่ยงปานกลาง (MODERATE):** เช่น Metformin + มะระขี้นก (น้ำตาลตกเฉียบพลัน), Enalapril + เพชรสังฆาต (โพแทสเซียมสูง)
  - **ความเสี่ยงต่ำ (LOW):** การรบกวนการดูดซึมหรือการง่วงซึมเล็กน้อย

### 3.5 แผนการรักษาและการติดตามผลรายเดือน (Care Plan & Cadence Engine)
- คำนวณความถี่การนัดติดตามผลตามหลักวิชาการ (Academic Cadence):
  - **กลุ่มเสี่ยงสูง (High Risk):** นัด 4 ครั้งในเดือนแรก (สัปดาห์ละ 1 ครั้ง), 2 ครั้งในเดือนที่ 2, 1 ครั้งในเดือนที่ 3-6
  - **กลุ่มเสี่ยงปานกลาง (Moderate Risk):** นัด 2 ครั้งในเดือนแรก (ทุก 2 สัปดาห์), 1 ครั้งในเดือนที่ 2-6
  - **กลุ่มเสี่ยงต่ำ (Low Risk):** นัด 1 ครั้งต่อเดือน

## 4. รายละเอียดผลลัพธ์ที่ส่งออก (Output Specifications)

### 4.1 หน้าจอแสดงผลทางคลินิก (Clinical UI Dashboard)
- **Element Balance Radar Chart:** เรดาร์ชาร์ตเปรียบเทียบคะแนน 4 ธาตุ
- **Dual Diagnosis Card:** การ์ดวินิจฉัยคู่ขนาน ICD-10 ↔ ICD-10-TM พร้อมฟังก์ชันแก้ไขรหัส
- **Emergency Referral Modal (SBAR):** ใบส่งต่อฉุกเฉินระบุ Situation, Background, Assessment, Recommendation
- **NLEM Formulary Catalog:** บัญชียาหลักแห่งชาติแผนปัจจุบัน 1,080 รายการ แบ่ง 17 หมวดโรค ค้นหาและนำเข้า 1-Click
- **Prescription Sheet:** ใบสั่งยาอิเล็กทรอนิกส์พร้อมตารางยา รหัส 24 หลัก และบันทึกคำเตือน HDI
- **Longitudinal Trajectory Dashboard (Recharts):**
  - กราฟแนวโน้มระดับความปวด (VAS Pain Trend)
  - กราฟการปรับสมดุลตรีธาตุ (Tridosha Equilibrium Convergence)
  - กราฟความเสถียรของสัญญาณชีพ (Vital Signs Stability)
  - กราฟคะแนนสุขภาพองค์รวม (PROM Health Score)

### 4.2 ข้อมูลมาตรฐานส่งออก (Standard Export Formats)
- **MOPH 43-Folders Schema:**
  - แฟ้ม `DRUG_OPD`: รหัสยา 24 หลัก, จำนวน, วิธีใช้, ราคา
  - แฟ้ม `DIAGNOSIS_OPD`: รหัสโรค ICD-10-TM (กลุ่ม U) และ ICD-10 สากล
  - แฟ้ม `PROCEDURE_OPD`: รหัสหัตถการไทย สนย.
- **HL7 FHIR MedicationRequest JSON:** โครงสร้าง FHIR R4 พร้อม DosageInstruction และ Clinical Decision Support Note
