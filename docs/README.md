## ระบบประกอบด้วยอะไร

**ยายพร้อม** แอปดูแลสุขภาพระยะยาวสำหรับวัย 40–75 ปี (เมนูล่าง 5 แท็บ: หน้าหลัก, แนวโน้ม, สมุนไพรไทย, เส้นทางของฉัน, โปรไฟล์)
- บันทึกสุขภาพด้วยเสียงภาษาไทยหรือแตะเช็กอิน (การนอน ความสดชื่น อารมณ์ การเคลื่อนไหว) ผู้ใช้ตรวจก่อนบันทึกทุกครั้ง
- แนวโน้ม 7/30 วัน ค่าปกติส่วนตัว (ต้องมีอย่างน้อย 10 วัน) และข้อสังเกตเชิงสังเกต ไม่มีคะแนนรวมหรืออายุชีวภาพ
- กิจกรรมก้าวเดิน: เป้าก้าวต่อวัน ใส่ก้าวเองหรือเชื่อมอุปกรณ์ (จำลอง) กราฟ 7 วัน ชวนเพื่อนเดิน
- สมุนไพรไทย 91 รายการ: ข้อบ่งใช้ตามบัญชียาหลัก ค้นงานวิจัย PubMed สด ข้อควรระวัง อันตรกิริยากับยา และการเทียบรสยากับธาตุของผู้ใช้
- ยาและการดูแล: สแกนฉลาก (OCR) ยาไม่มีฉลาก Evidence Passport เตือนกินยา แผนยาที่แพทย์ยืนยันจาก CareBridge
- โปรไฟล์และความเป็นส่วนตัว: ความยินยอม ยกเลิกได้ ประวัติการเข้าถึงข้อมูล

**CareBridge** สำหรับแพทย์แผนปัจจุบันและแพทย์แผนไทย
- หน้าหลักแพทย์ ติดตามผู้ป่วยที่ยินยอม คัดกรองคู่สมุนไพร-ยาที่อาจตีกัน ส่งข้อความหาผู้ป่วย
- ประเมินสมุฏฐานธาตุ สั่งยาพร้อมเตือนอันตรกิริยา บัญชียาหลักแห่งชาติแผนปัจจุบัน 1,080 รายการ
- คลังงานวิจัย PubMed, peer review → Guideline, Clinical Handover (SBAR)
- แบบจำลองรายได้ (`#/business`) และการศึกษาความเป็นไปได้ (`#/feasibility`)

## วิธี deploy

GitHub Actions ไม่ได้ deploy ให้อัตโนมัติ ทำด้วยมือหลังผ่าน `npx tsc --noEmit`, `npm test` และ `npm run build`: push `main` แล้วคัดลอก `dist/` (ไม่รวมไฟล์ `.map`) ขึ้น branch `gh-pages` พร้อมไฟล์ `.nojekyll`

ข้อมูลอันตรกิริยาจากมหิดลสร้างใหม่ได้ด้วย `node scripts/importMedplant.cjs <medplant_interactions_long.csv>` (อยู่ระหว่างขออนุญาตเผยแพร่จากเจ้าของข้อมูล)
