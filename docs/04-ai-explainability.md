## 1. ปรัชญาการออกแบบ: หลีกเลี่ยง Black Box ในบริบทสุขภาพ (Explainable by Design)

ในการแพทย์แผนไทย การวินิจฉัยโรคผูกพันกับความเชื่อมั่นทางวิชาชีพและกฎหมาย หากใช้โมเดล Deep Learning แบบ Black Box ที่บอกเพียงว่า "คนไข้ธาตุลมกำเริบ 85%" โดยไม่สามารถอธิบายได้ว่ามาจากปัจจัยใด แพทย์จะไม่กล้านำไปใช้ในเวชปฏิบัติจริง

**TTM Smutthan Engine** โดยทีม **VejVivat (เวชวิวัฒน์)** จึงใช้สถาปัตยกรรม **Deterministic Rule-based Core + NLP Voice Tokenizer + GenAI Narrative Layer**:
1. **Rule-based Engine (แกนหลักคำนวณ):** คำนวณคะแนนด้วยสูตรทางคณิตศาสตร์ที่โปร่งใส 100% สามารถตรวจสอบย้อนหลังได้ทุกคะแนน (Audit Trail)
2. **AI Speech-to-Text & Symptom Tokenizer:** ถอดรหัสเสียงภาษาไทย สกัดคำบอกอาการ และอัปเดตสมดุลธาตุแบบ Real-time
3. **Dual Diagnosis Inference Engine:** จับคู่กลุ่มอาการเพื่อวิเคราะห์รหัสสากล Conventional ICD-10 และรหัสแผนไทย ICD-10-TM แบบคู่ขนาน
4. **Red Flag & Procedure Safety Rules:** คัดกรองอาการฉุกเฉินและข้อห้ามนวดไทยอย่างเข้มงวด พร้อมสร้างใบส่งต่อ SBAR
5. **GenAI Narrative Layer (การสังเคราะห์ข้อความ):** ใช้ LLM ในการแปลงคะแนนและกฎเกณฑ์ให้ออกมาเป็นภาษาการแพทย์ที่กระชับ เหมาะกับการบันทึกลงเวชระเบียน (Subjective/Objective Notes)

## 2. โมเดล AI Speech-to-Text รับเสียงคนไข้บอกอาการ (Voice Symptom Tokenizer)

เพื่ออำนวยความสะดวกในการซักประวัติและดักจับคำบรรยายอาการของผู้ป่วย ระบบได้ติดตั้ง **โมเดล AI Speech-to-Text**:

```
┌─────────────────┐      ┌──────────────────────────┐      ┌────────────────────────┐
│  ไมโครโฟนตรวจโรค │ ───> │  Web Audio / Speech API  │ ───> │  Thai NLP Tokenizer    │
│  (Patient Voice)│      │  ถอดรหัสคลื่นเสียงสด     │      │  สกัดคำศัพท์อาการภาษาไทย│
└─────────────────┘      └──────────────────────────┘      └───────────┬────────────┘
                                                                       │
                                 ┌─────────────────────────────────────┘
                                 ▼
┌───────────────────────────────────────────────────────────────────────────────────┐
│ อัปเดตเข้าระบบ Symptoms ทันที -> Recalculate ธาตุ 4 กอง & แนะนำรหัส ICD-10 อัตโนมัติ │
└───────────────────────────────────────────────────────────────────────────────────┘
```

- **การประมวลผลเสียง:** ตรวจจับสัญญาณเสียงพูดภาษาไทยผ่านไมโครโฟนเบราว์เซอร์ พร้อมแสดงกราฟคลื่นเสียงสด (Animated Audio Waveform)
- **คลังคำศัพท์อาการภาษาไทย (Symptom Dictionary):** สกัดคำสำคัญ เช่น "ปวดบั้นเอว", "ร้าวลงขา", "ชาปลายเท้า", "แน่นหน้าอก", "แสบท้อง", "เวียนศีรษะ", "ปวดศีรษะไมเกรน", "สะบักจม"
- **การเชื่อมต่อสด:** เมื่อสิ้นสุดการพูด คำอาการจะถูกเพิ่มเข้าสู่รายการอาการของผู้ป่วยทันที ส่งผลให้เรดาร์ชาร์ต 4 ธาตุและรหัสโรคคู่ขนานคำนวณใหม่แบบ 60 FPS

## 3. ระบบแนะนำการวินิจฉัยคู่ขนาน (Dual Diagnosis Standard: ICD-10 ↔ ICD-10-TM)

```
                  ┌──────────────────────────────────────────────┐
                  │   อาการสำคัญ & ข้อค้นพบ (Symptoms & Vitals)   │
                  └──────────────────────┬───────────────────────┘
                                         │
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │    AI Semantic & Keyword Matcher (40-98%)    │
                  └──────────────────────┬───────────────────────┘
                                         │
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
┌─────────────────────────────────┐             ┌─────────────────────────────────┐
│ รหัสโรคแผนปัจจุบันสากล (ICD-10) │ <─────────> │ รหัสการแพทย์แผนไทย (ICD-10-TM)  │
│ - แนะนำรหัสที่ใกล้เคียงอาการสุด  │   เทียบเคียง   │ - รหัสกลุ่ม U ตามคัมภีร์เวชกรรม │
│ - พยาธิสภาพ & การรักษาแผนปัจจุบัน │    คู่ขนาน    │ - แนวคิดสมุฏฐานธาตุ & หัตถการ/ยา │
└─────────────────────────────────┘             └─────────────────────────────────┘
                                         │
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │ Clinician Review & Override (Human-in-the-Loop)│
                  │ - เลือกยอมรับผลแนะนำ หรือแก้ไขรหัสได้อิสระ     │
                  └──────────────────────────────────────────────┘
```

1. **Symptom-driven ICD-10 Suggestion (แนะนำ ICD-10 จากอาการ):**
   - ประมวลผลจากอาการสำคัญและสัญญาณชีพ เช่น แน่นท้อง จุกเสียด -> แนะนำ **K30 (Functional Dyspepsia)**, มีไข้ ไอ เจ็บคอ -> แนะนำ **J00 (Common Cold)**, ปวดหลังส่วนล่าง ยอก -> แนะนำ **M54.5 (Low Back Pain)**
   - แสดงคะแนนความสอดคล้อง (Confidence Score 0–100%) พร้อมแท็กอาการที่ตรงกับเกณฑ์ (Matched Findings)
2. **Dual Comparative Synthesis (เทียบเคียง ICD-10-TM ทั้ง 2 ระบบ):**
   - จับคู่เทียบเคียงกับรหัสโรคการแพทย์แผนไทย (ICD-10-TM กลุ่ม U) แบบ Real-time ตามคู่มือเทียบโรค DTAM 2568
   - แสดงผลเปรียบเทียบเคียงข้าง (Side-by-Side Dual View):
     * **ฝั่งแผนปัจจุบัน (Conventional):** รหัส ICD-10, ชื่อโรคสากล, พยาธิสภาพ, และแนวทางการดูแลแผนปัจจุบัน
     * **ฝั่งการแพทย์แผนไทย (TTM):** รหัส ICD-10-TM, ชื่อโรคตามคัมภีร์, แนวคิดสมุฏฐานธาตุที่กำเริบ/หย่อน/พิการ, และหัตถการ/ยาสมุนไพรในบัญชียาหลักแห่งชาติ
3. **Human-in-the-loop Clinician Override:**
   - แพทย์สามารถคลิกปุ่ม **"แก้ไขรหัสโรค"** เพื่อพิมพ์ระบุรหัส ICD-10 และ ICD-10-TM ได้เอง พร้อมบันทึกเหตุผลทางคลินิก (Clinical Rationale) เพื่อความโปร่งใสและตรวจสอบย้อนหลังได้

## 4. ระบบคัดกรองความปลอดภัยฉุกเฉินและข้อห้ามนวดไทย (Red Flag & SBAR Safety Engine)

ความปลอดภัยของผู้ป่วยคือหัวใจสูงสุด ระบบจึงมีโมดูล `RedFlagService` เพื่อตรวจสอบสัญญาณอันตรายโดยอัตโนมัติ:

1. **เกณฑ์คัดกรองภาวะฉุกเฉิน (Emergency Red Flags):**
   - **โรคหลอดเลือดสมองเฉียบพลัน (Stroke FAST):** ปากเบี้ยว อ่อนแรงครึ่งซีก พูดไม่ชัด -> เสี่ยงอัมพฤกษ์/อัมพาต ต้องส่งต่อ CT Brain ด่วน
   - **กลุ่มอาการหลอดเลือดหัวใจเฉียบพลัน (ACS):** เจ็บแน่นหน้าอกร้าวไปกรามหรือแขนซ้าย เหงื่อแตกใจสั่น -> ต้องตรวจคลื่นไฟฟ้าหัวใจ EKG ด่วน
   - **ภาวะลิ่มเลือดอุดตันในหลอดเลือดดำส่วนลึก (DVT):** ขาบวมแดงร้อนข้างเดียว -> ห้ามนวดเด็ดขาด เพราะแรงนวดอาจทำให้ลิ่มเลือดหลุดไปอุดตันปอด (Pulmonary Embolism) ถึงแก่ชีวิต
   - **สัญญาณชีพวิกฤต:** ความดันโลหิต >= 180/110 mmHg หรือ มีไข้สูง >= 38.5°C
2. **ข้อห้ามทำหัตถการนวดไทย (Massage Contraindications):**
   - ตรวจพบการใช้ยาต้านการแข็งตัวของเลือด (เช่น Warfarin) หรือยาต้านเกล็ดเลือด (เช่น Aspirin, Clopidogrel) -> ห้ามนวดดัดดึงรุนแรงหรือกดจุดลึก เสี่ยงต่อการเกิดจ้ำเลือดใต้ผิวหนังและเลือดออกในข้อต่อ
3. **การออกใบส่งต่อแบบ SBAR Handover:**
   - เมื่อตรวจพบสัญญาณอันตราย ระบบจะแสดงแถบเตือนสีแดงสดพร้อมปุ่ม **"ส่งต่อแพทย์แผนปัจจุบัน (Emergency Referral)"**
   - สร้างเอกสารโครงสร้างสากล 4 มิติ: **S**ituation (สถานการณ์เร่งด่วน), **B**ackground (ประวัติยาเดิม/โรคประจำตัว), **A**ssessment (สัญญาณชีพและข้อค้นพบ), และ **R**ecommendation (คำแนะนำการส่งต่อแผนกฉุกเฉิน) พร้อมปุ่มพิมพ์และคัดลอกข้อความ

## 5. การควบคุม LLM และมาตรการป้องกันความปลอดภัย (GenAI Guardrails)

เพื่อให้แน่ใจว่า AI จะไม่แต่งข้อมูลขึ้นมาเอง (No Hallucination) ระบบมีข้อกำหนดในการป้อน Prompt อย่างเข้มงวด:
1. **Grounding on Deterministic Scores:** LLM ต้องอ้างอิงคะแนนและปัจจัยที่ Rule Engine คำนวณได้เท่านั้น ห้ามคิดคะแนนขึ้นมาใหม่
2. **Strict Medical Disclaimer:** ข้อความที่ส่งออกทุกครั้งต้องลงท้ายด้วยข้อความปฏิเสธความรับผิดชอบ
3. **Template Fallback Guarantee:** หากเครือข่ายขัดข้อง หรือไม่มี API Key ระบบจะสลับไปใช้ Structured Template ทันทีโดยไม่มีอาการหน้าค้าง
